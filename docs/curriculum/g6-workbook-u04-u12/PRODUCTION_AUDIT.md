## Production quality contract

- Source items are SOURCE-LOCKED to the uploaded scans; no replacement with unrelated textbook/general-knowledge exercises.
- Image/audio-only tasks are represented only in the source manifest as omitted evidence, never as fake online questions.
- Open writing/speaking tasks remain open (`responseMode: open`); the app does not invent a single answer key.
- Reading passages are stored with the source exercise and rendered at answer time for MCQ, Typing, True/False and matching.
- Unit modules are lazy-loaded and bounded: one module per Unit, one shared builder; no nine duplicated catalog/content architectures.
- Canonical CI must validate all published Sets before merge.
