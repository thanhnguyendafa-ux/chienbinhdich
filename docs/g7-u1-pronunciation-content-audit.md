# G7 Unit 1 /ə/ vs /ɜː/ Content Audit

## Source task words
occasion, world, girl, answer, heard, mother, birth, around, neighbour, work, early, upon, parent, learn, expert, singer, nature, sunburn, collect, shirt, monopoly, hurt, carrot, doctor, word, dirty.

## Target grouping used in the lesson
### /ə/
occasion, answer, mother, around, neighbour, upon, parent, singer, nature, collect, monopoly, carrot, doctor.

### /ɜː/
world, girl, heard, birth, work, early, learn, expert, sunburn, shirt, hurt, word, dirty.

## Teaching rules
- /ə/: focus on vowel reduction in weak or unstressed syllables, not on one fixed spelling.
- /ɜː/: use ir, ur, ear, wor as useful spelling clues within this word set.
- Do not teach spelling clues as universal rules.
- Explicit trap: final `er` does not automatically mean /ə/; compare mother with expert.

## Scaffold progression
Q1–Q3: weak/unstressed → /ə/.
Q4–Q7: spelling clues → /ɜː/.
Q8: block overgeneralisation.
Q9–Q11: word → clue → rule → sound.
Q12–Q17: six Mai Lan Hương-style classification rounds, maximum five words per screen.
